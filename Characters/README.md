# Character records

This directory contains narrow durable homes for project-character and user-continuity facts.

## Record types

Files labelled `character_continuity_record` extract established or unresolved project facts from the preserved Compendium and later scoped continuity records so routine character retrieval does not require re-reading the entire MASTER.

They are **derived continuity records**, not new witnessing evidence. The preserved source still controls the provenance and evidentiary strength of the claims extracted here.

`Fred.md` is a `user_continuity_record`. It preserves only project-relevant user-authored agency, knowledge, stated goals, and role boundaries needed for continuation. It is not a personality profile and does not authorize narration of Fred's private thoughts or decisions.

`Constantia-Serenitas.md` is different: it is an `INTERPRETATION / A6` simulation guide. It helps portray Constantia plausibly but does not create biography, relationship state, or accepted history.

`Constantia-Continuity.md` is the corresponding durable continuity record.

No equivalent A6 simulation guide currently exists for Aurelia, Justina, Eulalia, Valeria, the Helverin pilot, the Warhound Princeps, or the Paragon trio. Preserve their continuity records first and use current official Warhammer sources when role-specific lore materially affects portrayal.

## Routing

- current location and immediate operational pointer -> `../CURRENT_STATE.md`
- structured current staging -> `../Story/CURRENT_SCENE.yaml`
- durable event chronology -> `../Story/EVENTS.yaml`
- explicit knowledge-state retrieval -> `../Story/KNOWLEDGE.yaml`
- conversational adoption/writeback -> `../Story/ACCEPTANCE.md`
- Fred's bounded user continuity -> `Fred.md`
- durable principal-person facts -> the matching continuity record here
- durable interpersonal and functional relations -> `../Relationships/RELATIONSHIPS.md`
- underlying inherited evidence -> `../Order_of_the_Silver_Compass_MASTER_v4.3.41.txt`
- current Warhammer rules -> `../Rules/11e/`

A character or user-continuity record must preserve unresolved material rather than filling it for completeness.
