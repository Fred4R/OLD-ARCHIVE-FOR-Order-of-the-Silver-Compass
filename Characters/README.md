# Character records

This directory contains narrow durable homes for project-character continuity.

## Record types

Files labelled `character_continuity_record` extract established or unresolved project facts from the preserved Compendium and later scoped continuity records so routine character retrieval does not require re-reading the entire MASTER.

They are **derived continuity records**, not new witnessing evidence. The preserved source still controls the provenance and evidentiary strength of the claims extracted here.

`Constantia-Serenitas.md` is different: it is an `INTERPRETATION / A6` simulation guide. It helps portray Constantia plausibly but does not create biography, relationship state, or accepted history.

`Constantia-Continuity.md` is the corresponding durable continuity record.

## Routing

- current location and immediate scene state -> `../CURRENT_STATE.md`
- durable person facts -> the matching continuity record here
- durable interpersonal and functional relations -> `../Relationships/RELATIONSHIPS.md`
- underlying inherited evidence -> `../Order_of_the_Silver_Compass_MASTER_v4.3.41.txt`
- current Warhammer rules -> `../Rules/11e/`

A character record must preserve unresolved material rather than filling it for completeness.
