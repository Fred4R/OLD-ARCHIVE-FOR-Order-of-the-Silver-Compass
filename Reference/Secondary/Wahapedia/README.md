# Wahapedia secondary reference

This directory contains imported Warhammer 40,000 reference data from Wahapedia.

## Status

- Source class: secondary reference.
- Authority: non-authoritative for current Warhammer rules and lore.
- Freshness: time-sensitive; an import date or upstream `Last_update.csv` value does not prove that every field is current.
- Project status: reference material only. Presence here does not create or alter Silver Compass canon, continuity, biography, relationships, roster history, or fictional chronology.

## Permitted use

Use this dataset for discovery, comparison, indexing, coverage checks, and locating candidate rules fields that may warrant official verification.

For any current-rules claim, verify the exact field against the controlling current official Games Workshop/Warhammer source before recording it as current under `Rules/11e/`.

## Prohibited promotion

Do not treat agreement with this dataset, by itself, as sufficient to:
- mark a rule `verified_current`;
- replace or supersede an official Games Workshop/Warhammer source;
- fill a repository field marked `not_yet_verified` or `blocked_current_source`;
- silently rewrite historical roster snapshots;
- infer project events, ownership, casualties, arrivals, departures, motives, relationships, or character knowledge.

If this dataset conflicts with a current official source, the official source controls the current-rules question. Preserve the discrepancy as a secondary-source mismatch if it is useful to record; do not reconcile it by invention.

## Routing

For current rules, start with `Rules/11e/SOURCE_INDEX.md` and the matching repository rules record, then consult the current official source for the exact field at issue.

For repository-wide source precedence and supersession, use `AUTHORITY.md` and `SOURCES.md`.
