# New Conversation Bootstrap

This file is a minimal handoff for a fresh conversation. It is routing, not canon.

## Start

Read `CURRENT_STATE.md` first.

That file contains the compact operational present: current scene, immediate focus, principal people, authority boundaries, relationship safeguards, army pointers, rules gates and unresolved matters that actually affect continuation.

Do not make Fred restate information that the repository already contains.

Do not preload the entire Compendium or the entire governance layer merely because the conversation is new.

## Then route by task

For story continuation, use `CURRENT_STATE.md` and retrieve only the character, relationship, rules or Compendium detail the immediate scene requires.

For army questions:
- exact supplied roster -> `Sources/Armies/`;
- repository mapping -> `Armies/`;
- current rules -> `Rules/11e/SOURCE_INDEX.md` and the matching current record.

For canon, evidence, conflict or supersession questions, use `AUTHORITY.md`, `STATUS.md`, the relevant preserved Compendium section and any later scoped record.

For personal identification, use the original methodology PDFs under `Sources/Methodology/` by function.

For repository maintenance, use `USING_REPOSITORY.md` and the merge/validation contract there.

For continuation planning rather than immediate continuation, use `CONTINUATION.md`.

## Project purpose

The repository exists to help Fred enjoy, understand and develop the Order of the Silver Compass, House Montfort and the `True Meridian`, his Warhammer 40,000 armies, official lore and current rules, character relationships and continuity, personal identification work grounded in appropriate methodology, and immersive fiction.

GitHub is durable storage and version history. It is infrastructure, not the experiential goal.

## Truth discipline

Keep exact source evidence, current official rules/lore, established project canon, historical roster snapshots, human evidence, interpretation, proposal, unresolved information and workflow state distinct.

A later record supersedes an earlier record only for the field or scope it explicitly controls.

Never repair contradictions by inventing departures, casualties, names, motives, relationships, chronology, ownership, institutional merger, rearmament or rules results.

A retrieval failure is a route failure, not proof that a source does not exist.

## Conversation behavior

A fresh conversation should feel continuous, not reset.

Ask Fred only when missing information would materially change canon, factual meaning or the requested result. Otherwise retrieve, distinguish and proceed.

For story, tell the story rather than an audit.

For army learning, teach causally.

For identification, compare rigorously.

For repository work, preserve and verify.

Routine retrieval, source routing, diffing, arithmetic, cross-reference checking and validation belong to the assistant rather than Fred.
