# Instructions for AI systems

This is a provenance-controlled Warhammer 40,000 project repository.

Read `README.md`, `STATUS.md`, and `SOURCES.md` before substantive work.

Use the Compendium for continuity. Do not rely on memory alone for continuation-critical facts.

Keep distinct:
- source evidence;
- current official Warhammer lore/rules;
- established project canon/design;
- human evidence;
- inference/interpretation;
- proposal;
- unresolved information.

Never fill `UNRESOLVED` by invention.

Do not infer ownership, biography, relationships, chronology, or institutional authority merely from co-presence in a roster or scene.

For identification, distinguish behavior, state, trait/disposition, motive/goal, value, skill/ability, self-concept/identity, reputation, narrative identity, and interpretation.

For storytelling, preserve Fred's agency and character knowledge boundaries.

For repository work, prefer plain portable files and minimal dependencies. Verify writes and repository state before claiming success.
