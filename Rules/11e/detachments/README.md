# 11th-edition detachment records

Detachment records are the canonical repository home for current Detachment-specific rules fields that have been verified from official Games Workshop sources.

Use `../SOURCE_INDEX.md` first, then the matching record under this directory.

These records separate:
- Codex origin and edition carry-forward;
- current Detachment Points and Force Disposition;
- current Enhancement names and points;
- current amendments;
- publicly verified rule text;
- Codex/app-only fields that remain unverified or blocked;
- project interpretation used for tactical teaching or story simulation.

They do not rewrite historical roster snapshots or create project biography, relationships, theology, or story chronology.
