# 11th-edition system rules

These records hold current game-wide Warhammer 40,000 rules concepts that connect multiple factions, armies, and future tactical questions.

Use `../SOURCE_INDEX.md` first. System records do not replace faction datasheets, Detachment records, Codexes, Faction Packs, mission records, or historical roster snapshots.

Current system records:
- `ARMY_CONSTRUCTION.yaml` — verified army-construction structure shared across factions.
- `MISSIONS.yaml` — Force-Disposition mission generation, casual/event distinctions, Secondary structure and scoring boundaries.
- `TERRAIN_AND_OBJECTIVES.yaml` — terrain-area/objective interaction and time-sensitive layout boundaries.
- `SOURCE_AND_UPDATE_ROUTING.yaml` — project routing for finding the current official source for different rule questions.

The current public construction evidence directly verifies Incursion and Strike Force parameters. It does not establish a current 3,000-point construction row, so the historical `FORCE-3000` snapshot must not be treated as a certified current 11th-edition 3,000-point format from this record alone.

Exact event-layout geometry remains time-sensitive. Current system records preserve stable mission and terrain concepts while routing precise competitive layouts back to the live app/current official event and update material.

System records explain permissions, dependencies, and consequences. They do not create project canon or fictional chronology.
