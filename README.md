# Order of the Silver Compass

This repository is the durable home for the Order of the Silver Compass project.

## What matters most

The project exists to support Fred's Warhammer 40,000 experience: armies, lore, characters, relationships, identification, continuity, and immersive fiction.

GitHub is storage and version history. It is not the meaning of the project.

## Start here

1. Read `STATUS.md` before treating any statement as accepted canon.
2. Read `SOURCES.md` to understand which source governs which kind of question.
3. Use `COMPENDIUM_MASTER_v4.3.41.txt` as the preserved migration/continuity source currently present in this repository.
4. Read `AGENTS.md` for short instructions to future AI systems.
5. Use `Armies/` for durable army-list reference records and roster-to-project mappings.
6. Use `Rules/11e/` for the 11th-edition official-rules crosswalk, source routing, stats/keyword fields, and verification status.

## Army and rules routing

Army exports and current rules answer different questions.

- The Compendium and `Armies/` preserve what a roster contained at a particular source snapshot.
- `Rules/11e/` records current official rules only to the extent those rules were actually retrieved and verified.
- A newer points value, keyword, ability or weapon profile does not rewrite an older roster export.
- Roster presence does not by itself establish story-scene presence, ownership, biography, casualty, reinforcement, rearmament or chronology.
- Project character mappings are separate from generic datasheet identity.

The first crosswalk pilot is `Armies/Order-of-the-Silver-Compass/FORCE-1985-V946.yaml`.
